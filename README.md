# Nike Website

A modern, responsive Nike-inspired e-commerce website built with **React, TypeScript, Vite, and Tailwind CSS**. The project focuses on creating a visually engaging shopping experience with a clean interface, product-focused layouts, and modern frontend development practices.

## Overview

The Nike Website is a frontend project inspired by the design language and shopping experience of Nike's official platform.

The goal of this project is to recreate a premium sportswear shopping experience while demonstrating modern frontend development concepts such as component-based architecture, responsive layouts, reusable UI components, TypeScript development, and optimized development workflows.

> This project is created for educational and portfolio purposes and is not affiliated with or endorsed by Nike.

## Getting Started

Follow the steps below to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Abhishek01samal/Nike-Website.git
```

### 2. Navigate to the project

```bash
cd Nike-Website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server
